# Product Principle — Convenience, Not Permission

## Working rule

**Pay for convenience, not permission.**

AXM Node Cartridge / AXM Magic Box should never need artificial scarcity around underlying capabilities in order to justify its value.

## Free path

Where source licenses and project boundaries permit, people should remain able to reach the same broad destination through public/free AXM material such as:

- capability research;
- public tools and software;
- documentation and state contracts;
- larger wired monoliths;
- human-accessible deterministic capabilities;
- enough research to understand the cartridge direction and independently build alternative approaches.

The free path may require more technical work, assembly, storage, configuration, integration, and maintenance.

## Support / paid path

If the Magic Box becomes a product, its value is the avoided work:

- capability normalization;
- node conversion;
- deduplication and composition;
- state wiring;
- dependency mapping;
- dormant/active lifecycle handling;
- host adaptation;
- compact packaging;
- testing and evidence;
- upgrades and compatibility work;
- portable user-friendly delivery.

Payment supports the engineering and convenience of the finished cartridge, not exclusive permission to use ideas or capabilities that are otherwise available.

## Anti-gating check

Before introducing a commercial feature, ask:

> Does this charge for real convenience/work, or are we intentionally making the free route worse so payment becomes necessary?

If the second answer is true, the direction has drifted.

## Source visibility

This repository intentionally exposes research for inspection, discussion, critique, and citation while reserving reuse of its protected implementation under the repository license.

That boundary is compatible with this product principle: people can learn from the research and independently explore the idea, while the finished AXM implementation remains a product asset.
